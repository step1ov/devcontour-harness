# devcontour-harness 0.1.0-alpha.44

Совместная проверка, прерванная до результата gates, больше не тратит
предел проверок набора, а исчерпанный набор можно освободить явным сбросом
с причиной. `stateVersion` и `policyVersion` прежние.

## Изменения

- **Прерванная совместная проверка не тратит предел набора.** `JointRunner`
  называет прерыванием остановку хоста (внешний сигнал, не обход зависших)
  и потерю владения (`LEASE_STALE`); истёкшую проверку, которую закрывает
  следующий `jointStart`, — движок сам. Движок сохраняет `interrupted: true`
  (и в `joint.finished`) только у проверки без evidence. Отказ gate, отказ
  до gates без отметки (результат поручения вне target ref, отказ
  подготовки) и прерывание после evidence тратят предел, как раньше. У
  прерываний свой предел `MAX_NEUTRAL_FAILURES`, как у незасчитанных отказов
  окружения поручений. Текст `ATTEMPTS_EXHAUSTED` называет число и выход.
- **Явный сброс бюджета.** `engine.jointBudgetReset(workIds, { reason, actor })`
  освобождает исчерпанный набор, снимая только его завершённые проверки без
  результата gates, в том числе отказы, записанные прежними версиями без
  отметки. Результаты gates тратят предел и после сброса. Сброс, после
  которого набор всё равно исчерпан (результатами gates или успешными
  проверками без принятия), или которому нечего снимать, отклоняется
  `ATTEMPTS_EXHAUSTED` и не записывается. Истёкшую проверку набора сброс
  сначала закрывает. Причина, актёр и IDs снятых проверок хранятся в
  пространстве `joint-budget-resets`, событие — `joint.budget-reset`; отчёт
  об эффекте считает сбросы по актёру (`autonomy.actions.recorded.jointResets`).
- **Договор хранилища.** `executionStoreContract` проверяет, что адаптер
  сохраняет `interrupted` совместной проверки и пространство
  `joint-budget-resets`; хост, заводящий проверку своей операцией, передаёт
  `startVerification`.

## Совместимость

- Хост со своим хранилищем отображает `interrupted` проверки и пространство
  `joint-budget-resets`, иначе прерванные проверки по-прежнему тратят предел.
  Хост передаёт `JointRunner.run` сигнал своей остановки. Сброс бюджета —
  действие оператора с причиной, а не автоматический ответ хоста на
  `ATTEMPTS_EXHAUSTED`.
- Проверки, прерванные до этого выпуска, отметки не имеют; набор,
  исчерпанный ими, освобождает `jointBudgetReset`.
- Состояние с `interrupted` или записями `joint-budget-resets` прежние
  версии отклоняют: откат — через копию. Без них откат возможен без
  изменений состояния.
