# devcontour-harness 0.1.0-alpha.25

Уточнение запроса ревью, сохранение отчётов упавших проверок и необязательная
граница бюджета принятых циклов для хостов. Форматы состояния и политики,
обязательные gates, fencing и привязка доказательств к SHA не меняются.

## Изменения

- **Пустая история находок.** Native reviewer явно получает требование
  `previous: []`, если controller ещё не выдавал находок. Ошибки прежних
  попыток и наблюдения gates остаются диагностическим контекстом; их нельзя
  превращать в ссылки на придуманные ID. Строгая проверка ответа и повтор
  после ошибки протокола сохраняются.
- **Отчёт при ненулевом коде.** Читаемый валидный JUnit сохраняется рядом с
  логом gate и при ненулевом коде команды, с прежней проверкой границ пути
  и маскированием секретов. Отчёт не превращает отказ в успех и не меняет
  класс настоящего отказа песочницы.
- **Бюджет принятого цикла.** Опциональный
  `BasisProvider.jointBudgetCheckpoints` сообщает успешно принятые хостом
  проверки и неизменяемые снимки IDs завершённых проверок на момент принятия.
  Движок проверяет границы и считает все последующие попытки того же набора
  вне объединения снимков. Новый ID набора, политика или постановка бюджет
  не закрывают; одного PASS без принятия недостаточно. Без hook действует
  прежний предел всей истории набора. Хост отвечает за доверенную локальную
  acceptance и сохранение снимка; активные проверки в снимок не входят.

## Обновление

Пакет alpha.24 остаётся неизменным. Перед обновлением остановите writers и
сохраните копию состояния. Активные попытки и совместные проверки закреплены
за начавшей их версией движка: новая версия их не продолжает. Преобразование
состояния не требуется. Новые сведения о продуктовой acceptance хранит хост;
hook не выдаёт перенесённую историю за локальный запуск проверок.
