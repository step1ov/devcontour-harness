# devcontour-harness 0.1.0-alpha.13

Controller mode для задач Relay и маршрут установки, который спрашивает только
на развилках. Gates, `maxAttempts`, бюджеты попыток и повторов, правила
находок, изоляция, принятие target ref и формат состояния не менялись.

## Что нового

- **`tasks[].context` и `contextDir` коннектора.** Задача Relay получает,
  кроме своего контекста, локальные пакеты из `<contextDir>/<id>` (по
  умолчанию `work/context` рядом с `connector.json`) — например, оверлей
  controller-mode из `templates/controller-mode/`. Пакет закрепляется в
  `context.json` снимка теми же правилами, что файловый контекст графа
  (`references/` — справки без вложения). Digest пакетов и их распределение
  по задачам входят в ревизию набора задач: изменённый пакет требует нового `source-snapshot` и
  согласования (`run --source` иначе отказывает `APPROVAL_STALE`). Semantic
  digest задачи от пакетов не зависит: включение поля или изменение пакета не
  делает доставку принятого результата конфликтом. Нет каталога или пакета —
  `NOT_READY` до чтения backend; `source-check` называет его в `problems`
  ([connectors](../connectors.md#локальные-пакеты-контекста)).
- **Пределы контекста при снимке.** `source-snapshot` проверяет пределы
  снимка контекста (размер файла, сумма, не больше 30 источников) и сообщает
  превышение как `LIMIT_EXCEEDED`, а не только отказом при запуске;
  `source-check` проверяет пределы локальных пакетов. Вывод
  `source-snapshot` и manifest называют закреплённые пакеты (`localContext`).
- **`controllerContext`** (`examples/turbo-starter/setup.mjs`) пересобирает
  пакет с пустого каталога и не берёт в справки `.harness/` и сам каталог
  пакета: повторная сборка внутри репозитория не вкладывает копии пакета и
  не оставляет справки удалённых AGENTS.md. `upstream: null` — сборка для
  обычного репозитория проекта.
- **Skill `harness-setup`:**
  - таблица «решить или спросить»: рутинные выборы (ветка, каталог
    установки, источник пакета, профиль, gates, согласование, completion)
    агент делает сам и объясняет в отчёте; спрашивает о вендорах
    writer/reviewer, ревью тем же вендором, controller mode (оверлей
    главнее правил продукта), пропуске проверки проекта или CI, недостающих
    фактах Relay, изоляции, Docker, конфликтах с правилами проекта, коммите,
    записи в Relay и живых вызовах;
  - pnpm/Turborepo-монорепо (Turbo Starter): локальный `.harness/profile.json`
    из команд проекта (`pnpm --filter`), test-gates с JUnit без новых
    зависимостей или приёмочные проверки в `.harness/acceptance/`, gate
    детерминизма генерации, защищённые пути, среда с Docker только по
    согласию;
  - controller mode: пакет собирается `controllerContext`, в Git не
    коммитится (`.git/info/exclude`, пересборка в новом клоне) и
    подключается к файловым графам и к задачам Relay (`tasks[].context`);
  - при обновлении — предложить новые возможности выпуска, не применяя их.

## Изменения договора

Добавления в конфигурацию коннектора: `contextDir` (строка) и
`tasks[].context` (1–10 ID); в manifest снимка и ответ `source-snapshot` —
`localContext` (только при пакетах). Без них снимок, ревизия набора, semantic
digest задачи, digest графа и контекста те же, что в alpha.12. Пакет с именем
вида ID контекста задачи (`c` + 20 hex) — `INVALID_INPUT`.

Изменение отказа: корень источника контекста через symlink (в файловом
графе и в пакетах коннектора) — `INVALID_INPUT` «Контекст не читается через
symlink» вместо `NOT_READY` «не найден»; symlink внутри источника и раньше
давал `INVALID_INPUT`.

## Совместимость

Формат состояния не менялся: alpha.13 читает всё, что читает alpha.12, а
alpha.12 — всё, что пишет alpha.13. Конфигурация коннектора с новыми полями
alpha.12 не принимает (строгая схема). Обновление и откат — по
[upgrade](../upgrade.md).

## Проверка выпуска

`npm run check` (lint, typecheck, schemas, build, весь набор тестов, package
smoke из установленного архива) на macOS arm64, Node.js 24.3. Тесты
коннектора на подделке backend (`tests/connector-context.test.ts`):

- пакет закреплён в снимке и поручении, его байты в контексте попытки
  writer; поручение принято и доставлено;
- без поля ревизия набора, digest задачи, графа и контекста совпадают со
  значениями alpha.12 (golden-тест, сверен с кодом тега);
- изменённый пакет — `APPROVAL_STALE` до запуска; перенос пакета между
  задачами и смена порядка — новая ревизия; больше 30 источников —
  `LIMIT_EXCEEDED`; доставка принятого
  результата после изменения пакета и после включения поля — не конфликт;
- нет каталога — отказ без обращений к backend; нет пакета, свой
  `contextDir`, конфликт имени, symlink-пакет, превышение пределов в снимке
  и `source-check`, `localContext` в manifest.

Пересборка `controllerContext` после коммита пакета и удаления AGENTS.md —
`tests/starter-setup.test.ts`. Тест skill сверяет команды, флаги,
обязательные аргументы и пути `<pkg>/…` с поставкой. Живые модели и
настоящие Relay не вызывались; W01 на настоящих Relay для alpha.13 не
повторялся.
