# devcontour-harness 0.1.0-alpha.36

Факты проекта только для чтения и установка зависимостей исполнителя до его
запуска. `stateVersion` и `policyVersion` прежние.

## Изменения

- **Факты проекта.** `inspectProject({ repository })` из корня пакета и
  договор `project-facts`: Git (корень, связанное рабочее дерево, база, ветка,
  первые 50 изменённых путей и их общее число), lockfiles, менеджер пакетов,
  профили, скрипты, проверки, инструменты и CLI runtimes (`available`,
  `missing`, `version-error`; авторизация `unknown`) с диагностиками и
  действиями. Инспекция ничего не пишет (в том числе индекс `.git`) и не
  исполняет скрипты проекта; `init` использует те же Git-факты.
- **Зависимости исполнителя.** Перед исполнителем, после наложения черновика
  прежней попытки, controller исполняет в его дереве обязательные gates
  установки попытки под изоляцией gate, без evidence (стадия
  `writer-dependencies`). Следы установки в работу исполнителя не попадают;
  правка отслеживаемых файлов откатывается (`reverted`). Отключение —
  `repositories[].writerDependencies: false`.

## Обновление

Новые поля необязательны, но строгая схема прежних версий не принимает
`writerDependencies`: при откате уберите его из политики. Подробнее —
`docs/upgrade.md` и `docs/toolchains.md`.
