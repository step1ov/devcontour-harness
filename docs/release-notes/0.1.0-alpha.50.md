# devcontour-harness 0.1.0-alpha.50

Выпуск собирает шесть изменений: ведущий и решение о ревью в `init`, пробу
портов ресурсов перед фазой, предупреждения `doctor` (срок фаз, ресурсы
машины, хранилище зависимостей), команду `harness gates`, слой профиля
`lean` и перенос evidence кандидата на интеграцию. `stateVersion`,
`policyVersion` и `manifestVersion` прежние; политики без новых полей и их
digest не меняются.

## Изменения

- **`init --lead`, `--review`, `--model`.** Ведущий (`--lead claude|codex`) —
  автор планов и контрактов; без флага он берётся из manifest, сохранённой
  политики, признака сессии или `--writer`, иначе `NOT_READY`
  (`lead-unknown`): молчаливого `--writer claude` больше нет. `--writer` по
  умолчанию — ведущий. `--review cross|same|auto` (умолчание `auto`):
  без CLI другого вендора — тот же runtime с явным
  `vendor: same-vendor-allowed` и предупреждением `review-same-vendor` в
  `init`, `doctor` и `report`. `--model` закрепляет одну модель на writer и
  всех reviewers (с ревью двух вендоров — `INVALID_INPUT`). Manifest хранит
  `lead`, `review`, `model`; ответ `init` дополнен `lead`, `review`,
  `runtimes` и `warnings`.
- **Проба портов ресурсов.** Перед каждой фазой аренды (lifecycle, prepare,
  gates, `runGatesAt`) controller пробует каждый ресурс `port`. Порт,
  занятый пережившим остановку процессом прежней попытки (таблица
  `survivors`), освобождается; занятый иным процессом — отказ `environment`
  с новой причиной `resource-busy`, попытка не засчитана. Порт, занятый
  только на wildcard-адресе при свободном loopback (AirPlay Receiver на
  macOS, порты 5000 и 7000), даёт предупреждение. `doctor --policy`
  показывает `ports[]` и называет занятый порт в `problems`.
- **Предупреждения `doctor`.** С политикой ответ несёт `warnings` (строки,
  не отказ; `problems` и exit code не меняются): порт только на wildcard,
  ревью тем же вендором (`review-same-vendor: …`), сумма пределов шагов фазы
  больше `runTimeoutMs` (с самой длинной цепочкой `dependsOn`), советы о
  машине — `LOW_RESOURCES`, `DEPENDENCY_STORE_RECOMMENDED`,
  `DIGEST_THREADS_INVALID`. Необязательный шестой параметр библиотечного
  `doctor` — объект `{ resourceDatabase, planAuthors }`.
- **Срок фазы в политике `init`.** Если пределам шагов профиля не хватает
  умолчания `runTimeoutMs`, `init` записывает его явно (наибольшая сумма
  фазы × 1.25, вверх до 5 минут, не меньше срока профиля или слоя). Уже
  записанная политика не переписывается.
- **`harness gates`.** `gates --state D --sha SHA|HEAD [--gate a,b]
[--repository ID] [--fail-fast] [--human]` исполняет gates на коммите вне
  попытки поверх `runGatesAt` и не пишет попыток. `runGatesAt` получил
  `failFast` и аддитивные поля результата `skipped`, `interrupted` и
  `warnings`; прерывание — отказ `CANCELLED`.
- **Слой `lean` и `init --lean`.** Встроенные слои профилей лежат в
  `profiles/layers/`; `lean` задаёт `concurrency: 1`, `runTimeoutMs: 1800000`
  и новое поле профиля `gateTimeoutFloorMs` (240000). `init --lean`
  применяет слой, записывает его в manifest (`profile.layers`) и для
  pnpm-проекта добавляет `dependencyStore`. `generatePolicy` переносит
  параллельность и пределы профиля в политику.
- **`integrationReuse: 'identical-tree'`.** При дереве integration-коммита,
  равном дереву кандидата, прошедшие на кандидате gates пишутся на
  интеграции взятыми из него (`reusedEvidence`), а при полном переносе
  окружение интеграции не поднимается (с потребителями — поднимается
  всегда). Хост, который ведёт попытки сам, должен объявить
  `capabilities.integrationReuse`.
- **`docs/upgrade.md`.** Раздел «Следующий выпуск» переименован в
  «0.1.0-alpha.50» и объединяет заметки всех изменений.

## Совместимость

- Строгие схемы прежних версий не принимают `gateTimeoutFloorMs` в профиле,
  `profile.layers`, `lead`, `review`, `model` в manifest, `integrationReuse`
  в политике и записи с `reusedEvidence`; откат с событием
  `attempt.diagnosed` `cause: resource-busy` — через копию базы. Подробности
  и порядок отката — [upgrade](../upgrade.md).
- Скрипт, вызывавший `init` без `--writer` вне сессии Claude Code, передаёт
  `--lead`.
