# devcontour-harness 0.1.0-alpha.10

Каталог общих операций агентского слоя и границы ответа. Gates, `maxAttempts`,
бюджеты попыток и повторов, правила находок, изоляция и принятие target ref не
менялись.

## Что нового

- **`harness capabilities`** — каталог общих операций (`init`, `explain`,
  `plan-request`, `plan-check`, `capabilities`): описание, `readOnly`, JSON
  Schema входа и данных ответа и пределы UTF-8 байт. Каталог строится из
  договора CLI — одна декларация (`sharedOperations`), второй копии описаний
  нет. Только чтение.
- **Граница транспорта общих операций**: значения аргументов больше 100000
  байт — `INVALID_INPUT` (путь `argv`); конверт ответа больше 1048576 байт —
  `RESPONSE_TOO_LARGE`, exit 2, данные не усекаются, с `--human` — тот же JSON.
  Прочие команды и содержимое файлов-входов граница не ограничивает.
- **Операции для хостов**: `operationCatalog` (каталог хоста тем же
  построителем, отдельно от каталога harness), `jsonBytes`, `checkJsonBytes`,
  `utf8Bytes`, `pageItems` — страницы с cursor (`json-base64url` с привязкой к
  ревизии и запросу или `digest-offset`; чужой или устаревший cursor —
  `REVISION_CONFLICT`, не помещающийся элемент — `RESPONSE_TOO_LARGE`).
- `resolveProfile(ref, { includeLeafContent: true })` дополнительно возвращает
  текст файла листа (`leafContent`); digest и прочие поля не меняются.

## Изменения договора

Только добавления:

- CLI-команда `capabilities` (`writes: false`), схема данных
  `operationCatalogSchema` в `cliDataSchemas`;
- `CliArgument.multiple` (у `plan-request --requirements`);
- тип `ResolvedProfileWithLeaf`, опция `ResolveProfileOptions.includeLeafContent`;
- код `RESPONSE_TOO_LARGE` впервые выдаётся (граница CLI и `pageItems`).

Описание `init` в `cliCommands` уточнено: manifest до политики, политика
последней (так `init` и пишет). Прежние команды сохраняют конверт и exit codes.

## Совместимость

Формат состояния не менялся: alpha.10 читает всё, что читает alpha.9
([upgrade](../upgrade.md)).

## Проверка выпуска

`npm run check` (lint, typecheck, schemas, build, весь набор тестов, package
smoke из установленного архива) на macOS arm64, Node.js 24; package consumer
fixture проверяет каталог, байтовые проверки и страницы хоста против
дословных копий прежних алгоритмов DevContour. Ответы моделей в
fixture-маршрутах запрограммированы: это механика, не качество живого агента.
