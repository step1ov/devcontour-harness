# devcontour-harness 0.1.0-alpha.43

Остаточные исправления сверки защищённых путей после alpha.42: исчезновение
вложенного `.git` подготовки засчитывается только за настоящими каталогами,
подпись защищённого файла включает ctime. `stateVersion` и `policyVersion`
прежние.

## Изменения

- **Исчезновение `.git` подготовки — только за настоящими каталогами.**
  Вложенный `.git`, созданный подготовкой, по-прежнему может исчезнуть
  (уборка переносом родителя). Исчезновением теперь считается только путь,
  родители которого от корня до первого исчезнувшего звена — настоящие
  каталоги. Родитель, заменённый символьной ссылкой или файлом, — нарушение
  `scope-violation` (во время подготовки — `sandbox-policy`): прежде обход
  дерева не заходил в ссылку, и `.git` за ней выглядел убранным.
- **Подпись защищённого файла с ctime.** Сверка сравнивает файл по inode,
  размеру, mtime и ctime. Правка на месте в перенесённом наружу родителе,
  после которой `utimes` вернул mtime, больше не проходит незамеченной.
  chmod/chown, новая жёсткая ссылка и изменение расширенных атрибутов
  защищённого файла — тоже изменение. Подпись каталогов прежняя.
- **Подмодуль из индекса переносом не убрать.** Документация называет это
  явно: git хоста видит удаление отслеживаемого пути, и gate проваливается
  проверкой отслеживаемых файлов; уборка такого подмодуля — дело подготовки
  или teardown.

## Совместимость

- Шаг подготовки или установки, который меняет права (`chmod -R`), делает
  жёсткие ссылки (`cp -al`) или пишет расширенные атрибуты файлов `.idea`,
  `.vscode`, `.claude` или `.git` в дереве, теперь получает отказ
  (`sandbox-policy` при подготовке, `scope-violation` в работе исполнителя,
  установки или gate). Держите такие шаги вне проверяемого дерева. На macOS
  ctime меняет и запись расширенных атрибутов приложениями хоста (например,
  открытие файла в Finder) — не открывайте защищённые файлы worktree во
  время фазы.
- Окно между снимком и сверкой прежнее: процесс фазы, переживший её конец,
  может изменить дерево после сверки. Сверка рассчитана на завершённые
  процессы фазы.
- Откат возможен без изменений состояния.
