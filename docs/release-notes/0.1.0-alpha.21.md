# devcontour-harness 0.1.0-alpha.21

Исправление сверки защищённых путей: попытки исполнителя Claude Code снова
принимаются. Включает всё из [0.1.0-alpha.20](0.1.0-alpha.20.md). Формат
состояния, gates, правила находок, принятие target ref и `maxAttempts` не
менялись.

## Что исправлено

- **Пустые служебные каталоги исполнителя — не нарушение.** С alpha.19
  защищённые имена вне `node_modules` (каталоги IDE, конфигурация shell и git,
  `.claude`, `.git`) сверяются до и после работы исполнителя и каждого gate.
  CLI Claude Code создаёт пустой каталог `.claude/.cc-writes` (права 700) в
  каждом каталоге, где пишет файл, и любая попытка с записью отклонялась как
  `scope-violation` («Исполнитель создал или изменил защищённые пути…»). Теперь
  дерево из одних каталогов, без файлов и символьных ссылок, нарушением не
  считается, если до снимка пути не было или он тоже был без файлов: исполняемой
  конфигурации в нём нет. Правило общее, не только для `.claude`, и действует и
  вокруг исполнителя, и вокруг gates.
- **Остальное по-прежнему нарушение.** Любой файл или символьная ссылка внутри
  (`.claude/settings.json`, файл в `.claude/.cc-writes/`, `.vscode/tasks.json`),
  любое изменение защищённого пути, где раньше были файлы (в том числе
  `.git/hooks` с образцами), подложенные `.git/config` и hook. Корневой `.git`
  сверяется и как элемент: файл `.git` worktree, заменённый каталогом, —
  нарушение, даже если внутри одни пустые каталоги.

## Совместимость

Формат состояния и публичный API не меняются. Матрица —
[upgrade](../upgrade.md).

## Проверка выпуска

Новые тесты `sandbox-install` SBX06 и SBX07 проверяют сверку снимков: пустые
`.claude/.cc-writes` в корне и во вложенных каталогах и пустой `.vscode` не
нарушение; файл, ссылка, правка прежнего `.claude`, hook, замена файла `.git`
и вложенный `.git`-файл — нарушение. Тест `runner` T05 под песочницей ОС:
исполнитель, оставивший `.claude/.cc-writes`, принимается; добавивший
`.claude/settings.json` — `scope-violation`. Мутанты обнаруживаются: без
исправления падают SBX06 и T05, правило «любой `.claude` разрешён» — SBX06,
без отдельной подписи корневого `.git` — SBX07. Полный `npm run check`.
Живые модели не вызывались.
