# Внешний коннектор через порты

`connector.mjs` подключает вымышленный сервис задач как источник поручений
(`WorkSource`) и получатель результата (`ResultSink`). Политика — как в
`two-vendors/`. Контекст подключается так же портом `ContextSource`
(`snapshot(ids, at)` возвращает `ContextSnapshot` с содержимым файлов).

Гарантии не зависят от коннектора:

- граф проходит те же схемы и перекрёстные проверки, что из файла;
- повтор того же `source.revision` продолжает прежнюю работу, другой digest
  той же редакции — `REVISION_CONFLICT`;
- доставка отделена от исхода: принятый код не откатывается из-за
  недоступного сервиса, повтор доставки идёт с тем же ключом без моделей и
  интеграции; новая редакция в сервисе получает `conflict`;
- `trusts` решает только, принимать ли внешний receipt предпосылки; SHA
  предпосылки всё равно должен быть доступен из target ref.

Подключение нового источника не требует правки движка.
